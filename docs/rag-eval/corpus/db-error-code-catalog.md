# MySQL 错误码速查手册

本手册按错误码数值顺序整理服务端常见错误。每条给出触发条件与处理建议。
排查任何一条时，都应先完整记录错误文本与当时的执行语句。

ERROR 1005：无法创建表。多数情况下是外键定义有误导致建表被连带拒绝，
需先解决被引用表或外键本身的问题，再看这条错误。

ERROR 1006：无法创建数据库。通常是磁盘空间不足或实例级配额已满。

ERROR 1017：无法找到文件。表空间文件被外部移动或删除，需要从备份恢复。

ERROR 1022：无法写入，因为表中存在重复键。与 1062 类似但出现在建表或改表阶段。

ERROR 1040：连接数已达上限。需要调大最大连接数或排查应用侧连接泄漏。

ERROR 1044：指定用户对目标数据库没有访问权限。授权粒度是「用户 + 库」。

ERROR 1045：访问被拒绝。用户名、密码或来源主机不匹配。特别注意授权记录是
「用户名 + 来源主机」的组合，只授权了本机的账号从容器网络登录同样会被拒绝。

ERROR 1046：未选择数据库。连接建立后没有执行切换库的语句。

ERROR 1049：未知数据库。库名拼写错误，或该库已被删除。

ERROR 1050：表已存在。建表脚本被重复执行，应改为先判断再创建。

ERROR 1051：未知表。表名错误或已被删除。

ERROR 1052：列名有歧义。多表关联时列名在多个表里都存在，需要加表前缀。

ERROR 1054：未知列。列名拼写错误，或该列在本版本中已被改名。

ERROR 1062：唯一键重复。写入的数据与已有唯一索引或主键冲突。
批量导入脚本要保证幂等，可用插入忽略或冲突更新的写法改写。

ERROR 1064：SQL 语法错误。报错位置通常指向语句中第一个无法解析的片段。

ERROR 1071：索引键过长。单个索引列的长度超过了存储引擎允许的上限，
对长文本列应该只索引前缀。

ERROR 1072：表中不存在被引用的键。建立外键时，父表的被引用列上缺少所需索引。

ERROR 1091：要删除的对象不存在。删除索引或列时对象已经被删过了。

ERROR 1105：未知错误。通常是存储引擎抛出的底层错误被透传上来。

ERROR 1114：表已满。单个表的数据文件达到容量上限，需要开启自动扩展或拆分。

ERROR 1129：主机被列入黑名单。因连接失败次数过多被临时禁止连接，
排查密码错误或连接风暴后再等待解禁。

ERROR 1130：主机不被允许连接。实例只监听本机地址，或授权范围不包含来源主机。

ERROR 1136：插入的列数与取值个数不一致。属于开发期就该发现的错误。

ERROR 1142：表级权限不足。授权只给了库级权限，缺少表级操作权限。

ERROR 1146：表不存在。多见于连接到了错误的库。

ERROR 1158：网络读取错误。连接在传输中被中断，常见于超时或代理层切断。

ERROR 1175：处于安全更新模式，未带条件的更新被拒绝。属于客户端保护机制。

ERROR 1205：锁等待超时。事务持有的锁被他人长期占用。需要排查长事务，
并统一多表更新的加锁顺序以避免死锁。

ERROR 1213：检测到死锁，事务已被回滚。这是并发下的正常现象，应用层应当
实现带退避的重试，而不是把它当成严重故障。

ERROR 1215：无法添加外键约束。最容易被误判的一条：它通常不是权限问题，
而是父列与子列的类型、长度或排序规则不完全一致，也可能是被引用的列上没有索引。

ERROR 1216：添加外键失败，父表记录不存在。属于数据层面的问题，需先清理孤儿数据。

ERROR 1217：无法删除或更新父表记录，因为存在外键引用。处理方式与 1451 相同。

ERROR 1231：变量值设置不合法。配置项类型或取值范围错误。

ERROR 1264：值超出列范围。列定义的范围太窄，或写入的数据未经校验。

ERROR 1305：存储过程或函数不存在。名称错误，或该对象属于另一个库。

ERROR 1364：字段没有默认值。严格模式下，插入语句未给非空且无默认值的列赋值。

ERROR 1366：不正确的字符串值。字符集不匹配，常见于往字符集为拉丁的列写入中文。

ERROR 1406：数据过长。列长度不足，或字符集导致单字符占用字节数变大。

ERROR 1451：无法删除或更新父表记录，因为存在外键引用。删除或修改父表某行、
而子表仍有行引用它时触发，当前事务整体回滚，不会留下部分修改。
处理方式有三种：先清理子表的引用行、把外键改为级联删除、
或者调整业务逻辑改为软删除。生产环境禁止临时关闭外键检查来绕过。

ERROR 1452：无法添加或更新子表记录，因为父表没有对应记录。
与 1451 方向相反，属于写入孤儿引用。

ERROR 1553：无法删除索引，因为约束还需要它。删除被外键依赖的索引会失败。

ERROR 1690：数值超出范围。常见于无符号列做减法得到负数。

ERROR 1813：表空间已存在。建表时表空间名重复。

ERROR 1824：打开表失败。表定义损坏，需要从备份恢复。

ERROR 1836：读取表时列数或行数不匹配。表结构文件与数据文件不一致。

ERROR 2003：无法连接到服务端。网络不通、端口监听异常或防火墙拦截。

ERROR 2005：未知主机名。连接串里的主机名无法解析。

ERROR 2013：查询过程中与服务器的连接丢失。通常由服务端超时或重启引起。
