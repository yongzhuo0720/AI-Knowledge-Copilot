# 混合检索原理与参数说明

## 为什么不能只用向量检索

向量检索把整段文本压成一个语义点，对"意思相近"很擅长，但对专有名词、编号、缩写不敏感。
模型训练时很少见到具体错误码这类字符串，所以它们的向量方向会退化成"数据库报错"这种
泛化语义，导致含具体编号的片段和不含编号的片段排在一起，无法区分。

## 关键词检索补什么

关键词检索靠词频精确匹配，只要查询里的编号出现在片段中就能拿到高分，
正好补上向量检索最弱的一环。企业知识库里大量存在的工单号、错误码、版本号、类名
都属于这一类。

## RRF 融合

两路召回的分数量纲不同：向量相似度有固定上界，关键词分数没有上界。
因此不能直接加权求和，而是采用倒数排名融合，只使用名次不使用分数，
天然免疫量纲差异，且无需调参。

## 重排

融合之后再对候选做一次重排，把查询和每个候选放在一起逐条比较，精度更高。
本项目在未配置外部重排模型时，使用词权重加权的覆盖率作为轻量重排特征，
其中词权重取自关键词索引的逆文档频率，因此不需要额外维护停用词表。

## 可调参数

检索候选池大小决定融合前每路取多少条，过小会导致真正相关的片段进不了融合，
过大则增加重排开销。关键词检索的长度惩罚参数用于抑制长片段天然更容易命中的偏差。
