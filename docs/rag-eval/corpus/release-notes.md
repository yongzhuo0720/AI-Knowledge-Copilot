# 发布说明与数据库迁移约定

## V7 版本：账号管理员标记

V7 迁移脚本为应用账号表增加了管理员标记列，并在升级时把系统中最早创建的账号
引导为管理员，避免升级后无人能进入后台。脚本文件位于 db/migration/V7__add_user_admin_flag.sql。

## V8 版本：引用来源召回渠道

V8 迁移脚本为会话引用来源表增加了召回渠道列，用于记录每条引用片段是被向量召回
还是被关键词召回命中的。脚本文件位于 db/migration/V8__add_source_retriever.sql。

## 迁移脚本命名与执行规则

所有迁移脚本放在 db/migration 目录下，采用 V{序号}__{描述}.sql 的命名方式。
序号必须连续且唯一，服务启动时自动按序号顺序执行，已执行过的脚本不会被重复执行。
因此**已合并到主干的迁移脚本不允许再修改内容**，任何变更都必须新增一个脚本。

## 回滚策略

迁移脚本默认不提供自动回滚。需要回滚时单独编写补偿脚本，并先在预发环境验证。
破坏性变更（删列、改类型）必须拆成「新增 → 双写 → 切换读 → 删除旧列」多个版本逐步完成。
