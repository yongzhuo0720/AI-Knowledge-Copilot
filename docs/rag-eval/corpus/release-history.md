# 版本发布历史

本文件按版本号顺序记录历次发布的主要内容，供回溯与审计使用。
每次发布的具体技术细节应查阅对应的设计文档。

V1：项目初始化。建立后端服务骨架、数据库连接与基础配置加载。

V2：账号体系。加入注册与登录接口，密码采用加盐哈希存储。

V3：工作空间。引入工作空间概念，账号归属到工作空间下。

V4：文档解析任务表。为异步解析增加任务状态表，支持状态查询。

V5：知识库与文档。支持创建知识库、上传文档并建立向量索引。

V6：会话与消息。支持多轮会话、消息持久化以及引用来源保存。

V7__add_user_admin_flag：为应用账号表增加管理员标记列，并在升级时把系统中
最早创建的账号引导为管理员，避免升级后无人能进入后台。
脚本文件位于 db/migration/V7__add_user_admin_flag.sql。

V8__add_source_retriever：为会话引用来源表增加召回渠道列，用于记录每条引用片段
是被向量召回还是被关键词召回命中的。
脚本文件位于 db/migration/V8__add_source_retriever.sql。

V9：文件存储。对象存储接入，文档原件不再落本地磁盘。

V10：概览统计。增加工作空间维度的用量统计接口。

V11：检索调试页。把检索链路的关键中间结果暴露到界面上。

V12：后台管理。增加面向管理员的账号、工作空间与知识库管理能力。

V13：流式问答。回答改为逐字返回，降低首字节等待时间。

V14：引用溯源。回答中标注来源片段编号，界面上展示引用面板。

V15：Agent 能力。引入工具调用，由模型自行决定检索时机。

V16：会话管理增强。支持会话重命名、删除与标题搜索。

V17：文档处理重试。解析失败的任务支持手动重试与自动退避。

V18：健康检查与探针。增加存活与就绪探针，供编排系统使用。
