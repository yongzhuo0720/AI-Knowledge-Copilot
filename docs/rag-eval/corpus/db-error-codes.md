# 数据库错误码手册

## ERROR 1451：外键约束冲突

当删除或更新父表记录、而子表仍存在引用该记录的外键时，MySQL 返回错误码 1451，
并附加无法删除或更新的提示。事务会整体回滚，不会留下部分修改。

排查顺序：先确认子表中引用该父记录的行数，清空引用关系或改用 ON DELETE CASCADE，
再重试删除。生产环境禁止直接关闭外键检查来绕过该错误。

## ERROR 1215：无法添加外键约束

通常由字段类型或字符集不一致引起：父列与子列的类型、长度、排序规则必须完全一致。
InnoDB 还会要求被引用的列上存在索引，缺失时同样报 1215。

## ERROR 1062：唯一键重复

插入的数据与已有唯一索引或主键重复。批量导入时常见于重复执行了同一批脚本，
可先用 INSERT IGNORE 或 ON DUPLICATE KEY UPDATE 改写。

## ERROR 1045：访问被拒绝

用户名、密码或来源主机不匹配。注意 MySQL 的授权是「用户名 + 来源主机」的组合，
仅授权了 localhost 的账号无法从容器网络登录。
