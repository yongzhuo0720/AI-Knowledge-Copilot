## 版本决策

Java 使用 21 LTS。Python 3.13 目前可以保留用于通用脚本，但 AI 服务优先使用 Python 3.11 或 3.12 独立环境，以降低向量库、科学计算和模型依赖的兼容风险。

Docker Desktop 负责运行 MySQL、Redis、Milvus、MinIO 等基础设施，业务服务在开发初期优先本地运行，便于调试。

## 仓库约定

- 默认分支：`main`
- 业务代码按领域模块组织
- 配置和密钥不提交到 Git
- 每完成一个可验证模块再提交一次 Git
