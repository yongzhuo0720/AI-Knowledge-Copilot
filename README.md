# AI Knowledge Copilot

企业级 AI 知识助手平台，包含用户与权限、工作空间、知识库、RAG 问答和 Agent 工具调用能力。

## 当前阶段

第 0 阶段：项目系统设计与开发环境初始化。

## 技术基线

- Java 21
- Spring Boot 3.x
- Maven 3.9.x
- Vue 3 + TypeScript + Vite
- Python 3.11/3.12（AI 服务建议版本）
- MySQL 8
- Redis 7
- Milvus 2.x
- MinIO
- Docker Compose

## 目录

- `backend/`：Java 后端
- `ai-service/`：Python AI 服务
- `frontend/`：Vue 前端
- `deploy/`：容器化与部署配置
- `docs/`：架构、数据库、接口和面试文档
